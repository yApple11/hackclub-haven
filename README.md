# hackclub-haven
Rigid Elasticity

This game is about getting you're bouncy ball to the end without being hit/caught by the baseball bats, hands, and hammers. You play this with arrow keys and the spacebar and can be played on https://yapple11.itch.io/rigidelasticity. It was made by me (yaseenmb11@gmail.com), Emile (juewen109@gmail.com), and Yomi (yaina715@gmail.com). We used ai in order to create the respawn script and debug. AI was not used for any assets and it was all made by us.
